## 边界

- 个人单年资产独立于2024→2025可比队列；不能因为另一年缺资料而隐藏。
- 未覆盖、扫描件、未标价、类别未核实、部分解析均不显示成总资产为零。
- 空年报显示“报告未列示可计价资产”，不等同没有私人资产。资产未扣负债，非实时净资产。

## 共同股票与行业

- 默认资产截止年度2025；按年、党派筛选，每人该年最近提交的一份完整明细年报。
- 至少2名不同申报人列示同一证券代码才进入共同股票排行。本人/配偶/共同/子女不额外计人数，但保留各资产行的披露价值。
- 只接原分类股票，排除期权、基金、私人股票等；优先修复名称前缀中的真实代码，NYSE/NASDAQ交易所字样不是股票代码。
- 无可靠代码的行排除并计缺口；未知价值不补零，无上限保留“至少”。不同股票类别不擅自合并。
- 行业以Nasdaq股票筛选器2026-10-26快照为准，不冒称GICS；未匹配单列待分类。基金不穿透、行业人数不可相加。行业条长为金额下限，非涨跌或收益。
- 全部党派：482份2025完整明细，705共同标的；R250份/419标的、D229份/496标的；数字只代表已收录样本。

## 年度变化

独立严格核验队列46人（R25/D21），同一批人两年对照。对能匹配Nasdaq股票、名称不含基金/债券/期权标识的历史行保守归类，展示25种股票的披露变化。目前这些股票均仅有单人披露，不伪称共同股票；共同变化样本不足。

变化区间 `[本年下限−上年上限, 本年上限−上年下限]`；表示披露金额变化，不是实际回报。某年未列出表示队列未列示，不推断实际持仓为零。年度变化不把当前行业分类当作历史分类；不计算无依据的行业历史收益。
