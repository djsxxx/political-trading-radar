# 地图底图

NASA Blue Marble land/ocean/ice composite, 2048 × 1024, downloaded 2026-10-26.

Source: https://eoimages.gsfc.nasa.gov/images/imagerecords/57000/57730/land_ocean_ice_2048.jpg

Background: https://science.nasa.gov/resource/blue-marble/

Not live satellite imagery. Local texture is projected with the same d3 projection as the clickable boundaries. Approximate solar declination and UTC hour determine day/night shading; updated every minute. This is not a precise astronomical ephemeris or weather layer. Alaska/Hawaii use the existing inset projection, not their physical placement beside the mainland. Natural Earth boundary data is for navigation, not a position on disputed borders.
