# 政治人物地图 v6

## v8：独立入口、独立窗口（当前行为）
以本节覆盖旧v6/v7的嵌入式地图说明。人物架构主页面不再含地图，只有人物档案与资产查询及原有金融工具入口。侧栏“权力地图 ↗ 独立窗口”打开独立Electron窗口，重复点击复用已有地图窗口；右上“人物档案窗口”回到主窗口。两个窗口的州、党派、人物选择相互独立，读取相同真实数据缓存。

地图窗口固定布局，右侧唯一悬浮面板显示州人物/资产合计。点人物在同面板切换资产、家族社交及交易详情；点股票也在该面板显示行情。返回保留所选州。没有页面下面的第二套人物卡、统计和筛选。党派筛选合并为一套，地图配色与资产范围保持一致。地图本身不因选择或详情高度变化而移动。

浏览器版使用具名弹出窗口，可能受浏览器弹窗策略限制；桌面版使用真正的BrowserWindow。地图hash为#power-map，主窗口不带该hash。最新启动脚本指向release/political-radar-v8/mac-arm64/MXdai.app。

验收：TypeScript/生产构建、打包通过；桌面实际打开独立地图窗口；1440×900浏览器下点州→人物后地图矩形保持x25/y185/w970/h595，唯一面板1个、重复目录0个。真实资料与旧归档保留。

## v7 追加：州人物/资产与党派颜色
点击州之后，地图上方直接显示该州人物卡（中英文名、党派、职位、个人年度资产区间），可滚动、点击进入人物。地图右侧同时显示同州/党派范围的可用年报合计及覆盖人数，缺失不补零。

共和党红色#bd5f6a、民主党蓝色#4e9ccc。两党均有人物的州按已收录人物人数比例红蓝分色，不表示州长党派或选举结果。独立/其他无两党记录的州采用中性底色。红色和蓝色图层可独立开关，只影响地图颜色；全局党派筛选影响人物和资产范围。选中州用轮廓高亮，不覆盖党派填色。

最新桌面包release/political-radar-v7/mac-arm64/MXdai.app。旧v6保留。浏览器测试加州顶部54卡、47可用年报、最低5.0766亿美元；红/灰/蓝/恢复红蓝四状态核对通过。

2026-10-26。本地实现，未发布或推送远程。

## 使用
启动“打开政治人物雷达.command”。首页点击世界地图中的美国，进入按职位浏览层级从高到低排列的人物列表。世界其他地区只显示尚未接入，不能伪装成有当地数据。

- 全国职务：总统、副总统。国会：议长、领导层、委员会主席、普通议员。历史申报人排在最后。同层按英文姓名排列。不是法律上的统一隶属链或权力评分。
- 点击州地图或州下拉菜单：人物、党派人数、半年交易、年度资产与股票关联持有人使用同一州范围。全国职务不归到其出生州。党派筛选与州相交；职位筛选和搜索仅筛人物列表，页面明确说明。
- 点击人物：默认个人资产申报，显示中英文名、职位与代表州/选区，公开家族关系及来源、官网和社交外链。点击人物时地图高亮其代表州。
- 家族名单不与金融账户自动合并，不推断共同持股或把家属资产重复相加。年报保留本人/配偶/共同/子女标记。
- 股票卡和详情补入常见公司中文译名，原始英文与代码仍保留，中文名可搜索。未收录译名不编造。

## 资料与许可证
- 职位：白宫 https://www.whitehouse.gov/administration/ 、参议院 https://www.senate.gov/senators/leadership.htm 、众议院 https://www.house.gov/leadership 。领导层快照不是自动实时监测。
- 国会人物/任期/州/委员会/官方社交账号：https://github.com/unitedstates/congress-legislators ，公开领域资料。社交名录仅列职务官方账号，不猜竞选和私人账号。
- 中文姓名、公开亲属关系和部分头像来源：https://www.wikidata.org ，CC0结构化数据；逐人保存实体链接。中文可能包含地区译名及繁体字。亲属关系可能含历史婚姻，保留起止日期；不保证穷尽或实时。
- 世界地图：world-atlas / Natural Earth 公有领域地理数据，使用项目已有world-atlas、d3-geo、topojson-client，不新增地图依赖。
- 美国州界：us-atlas / US Census https://github.com/topojson/us-atlas ，公有领域地理数据。阿拉斯加与夏威夷采用插图投影；不在投影内的领地可用下拉菜单筛选。地图不表达争议边界立场。
- 年度资产沿用Civitas Research CC BY 4.0；股票行情与历史披露功能保留。

## 覆盖限制
541份扩展档案，498份有中文名、131份有公开家族关系、520份有官网及额外社交/机构渠道，2261个外链。46位委员会主席有委员会条目。历史交易新增人物可能缺扩展资料。

总统、副总统只接入人物资料，金融披露未接入，不填零。州长、内阁、司法人物尚未接入，因此不是完整美国所有公职人员名册。未收录账号和家属不代表不存在。

## 可复现检查
`node research/political-trades/build_profiles.cjs`：公开源采集，缓存原始响应，4秒间隔，限流时25秒退避。不在应用启动时抓取。

`node research/political-trades/audit_atlas.cjs`：唯一人物ID、排序、公开URL协议、地图USA和州几何、加州党派分项与年度资产汇总对账，不重复统计家属。

`npm run build`：TypeScript及生产构建。桌面打包：`electron-builder --mac dir --arm64 --config.directories.output=release/political-radar-v6`。

浏览器已核对：地图美国入口，加州地图点击，民主党相交筛选，中文“佩洛西”搜索、家族及官方社交链接，个人年度资产、总统优先排序与缺失年报提示；控制台错误列表为空。
